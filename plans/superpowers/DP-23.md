# DP-23 决策记录

本记录固化 [DP-23](https://weiperfect007.atlassian.net/browse/DP-23) HumanGate 与 `review_override` 的主流做法。不扩展范围：不把仅建议 / 信息的 Review 结论拉进人工门禁（见 [DP-22](https://weiperfect007.atlassian.net/browse/DP-22)），不实现超时自动放行（超时策略本期 OOS），不实现 Verifying 细节或后续票。

## 进入与等候

仅当双审查给出阻断、判定范式漂移，或两条都阻断且理由冲突时，该 Ticket Child 进入 `HumanGate`，并等候既有人工 Signal `review_override`。未出 Signal 之前不自动越过门禁，也不启动超时自动放行。两条冲突阻断时 `auto_arbitrated` 保持为假，Workflow 不做自动仲裁，仍由人裁。

仅建议或信息时仍按 DP-22 直达 `Verifying`。此时再发 `review_override` 会因不在 HumanGate 被拒绝，记入 `last_rejection`，阶段不变。

## 裁决与快照

`review_override` 必填 `ticket_id`、`decision`、`decided_by`；`reason` 可选。`decision` 接受 `放行` / `打回` / `否决`，或既有的 `approve` / `rework` / `reject`，解析后存为英文枚举。调用方传入的 `decided_at` 一律忽略，由 Workflow 用确定性的 `workflow.now()` 落时间。

合法裁决写入既有快照字段 `review.override`（Child `snapshot.review` / 父 `tickets[].review`），包含人、动作（中文标签）、时间与可选理由，不另开第二套 Query。Signal 本身也出现在 Temporal History。

- 放行：该 Ticket Child 进入 `Verifying`。
- 打回：仅该 Ticket Child 回到 `Implementing`，重新进入写码 / 交付物路径；不重置 `lock_scope` / `decide_scheme`，也不自动回退同胞 Ticket 或整条 Story。
- 否决：该 Ticket Child 进入 `Blocked` 并记未处理失败。父执行保持聚合 `Implementing`，等候对该票 `retry_ticket` / `drop_ticket`，或对 Story `abort`；不因单张否决自动把整条 Story 打进 `Blocked`。

错误阶段、未知 Ticket、缺必填或非法 `decision` 被拒绝，记入 `last_rejection`，阶段不变。Child 在尚未进入 HumanGate 时直接收到的 `review_override` 会被忽略，避免过期裁决在进门后被误用。

## 既有门禁

不回退 DP-22 双审查、2000 行硬闸门、审查只读、以及 `_start_eligible` / `ticket_event` 的依赖唤醒修复。也不回退 DP-21 交付物、DP-20 沙箱、DP-11 幂等、DP-16 / DP-17 / DP-18 / DP-19 门禁。父 / Child Workflow 不含 LLM / CLI / 文件系统写入。`reopen` 对审查裁决的继承仍为待证。

## 验收与测试

单元与 WorkflowEnvironment 测试证明：放行进 Verifying 且决策出现在快照与 History；打回只让该 Ticket 回到 Implementing，同胞与范围 / 方案不被推倒；否决只阻断该 Ticket，父执行仍为 Implementing；未出 Signal 前停在 HumanGate 且不超时自动放行；仅建议 / 信息仍跳过门禁，此时的 `review_override` 被拒绝；非法或错阶段 Signal 被拒绝并记入 `last_rejection`；冲突阻断仍等人裁，不自动选边。现场 History 打在已运行的官方 Temporal（`TEMPORAL_TARGET`，例如 `host.docker.internal:7233`），覆盖放行、打回、否决；使用临时授权树和假 Jira，不起临时 Temporal 服务，不写真实 Jira 票，不调用现场 Cursor CLI。若 Child 停在 HumanGate 或否决后停在 Blocked，断言后 abort / terminate；不 terminate 已完成的 Workflow。
