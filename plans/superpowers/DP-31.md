# DP-31 决策记录

本记录固化 [DP-31](https://weiperfect007.atlassian.net/browse/DP-31) 把 CHARTER 爆炸半径写成写码验收的主流做法：默认不自动 `push`、不自动合并、不自动改全局规则。不扩展范围：不产品化远程 PR 授权流程，不实现测试环境部署本身（见 [DP-43](https://weiperfect007.atlassian.net/browse/DP-43)），不自动晋升 L0 / 全局 Skill。

## 默认未授权

写码与交付路径默认视为未授权远程写。自动化过程不得执行 `git push`、`git merge` / `rebase`，不得修改全局 Git 规则，也不得打开远程 PR。产物只留在已授权 worktree 与本地分支。

开远程 PR 必须另有明确授权。授权条件未拍板前标 `待证`，任何当前取值（含空值或其他字面量）都按未授权处理。本票不发明已签字的授权开关或产品界面。

该默认与 [DP-20](https://weiperfect007.atlassian.net/browse/DP-20) 沙箱闸门、[DP-21](https://weiperfect007.atlassian.net/browse/DP-21) 交付物（`pushed` / `merged` / `remote_pr_opened` 默认为假，`pr_authorization` 为 `待证`），以及 [DP-30](https://weiperfect007.atlassian.net/browse/DP-30) 不自动关闭或合并已有远程 PR 保持一致。

## 指向生产的写必须被拒并留记录

任何生产发布，或对生产远程 / 生产分支的 push / 合并，必须被拒绝，且不得把 `performed` 记成已执行。拒绝记录写入：

- 可查询的父执行快照字段 `snapshot.remote_write_rejections`
- 进程内日志（供 Activity 与测试断言）
- 若提供证据目录，则再写一份 UTF-8 的 `remote-write-rejection.md`

测试环境受控发布仍是例外，且必须落在授权目标 `test` 内，由 [DP-43](https://weiperfect007.atlassian.net/browse/DP-43) 负责实现部署。本票不实现测试环境发布，只拒绝生产或非测试目标，并保留既有 `publish_to_test_env` 桩与 `authorize_test_deploy` 门禁。

## 非目标

不产品化 PR 授权流程。不实现 DP-43 测试环境部署。不自动晋升 L0 / 全局 Skill。不把 Jira 票标为 Done。不打开 GitHub PR。

## 验收与测试

单元与 WorkflowEnvironment 测试证明：默认路径不进行远程 push / 合并 / 开 PR；`pr_authorization` 为 `待证` 且视为未授权；指向生产的 push / 合并 / 发布被拒并留下记录（`performed=False`）；测试目标不被本模块当成生产拒绝，且本模块不执行部署。现场 History 打在已运行的官方 Temporal（`TEMPORAL_TARGET`，例如 `host.docker.internal:7233`），覆盖生产发布被拒并留下记录；使用假 Jira，不起临时 Temporal 服务，不写真实 Jira 票，不调用现场 Cursor CLI。
