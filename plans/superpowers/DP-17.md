# DP-17 决策记录

本记录固化 [DP-17](https://weiperfect007.atlassian.net/browse/DP-17) 人工 `decide_scheme` 留下方案取舍与假设分级的主流做法。不扩展范围：不实现 Spike 跑法（[DP-18](https://weiperfect007.atlassian.net/browse/DP-18)），不实现真实 RAG 检索边界（[DP-33](https://weiperfect007.atlassian.net/browse/DP-33)），不在本票拆齐 Ticket 清单或派 Coding Child（[DP-19](https://weiperfect007.atlassian.net/browse/DP-19)）。

## 拍板写入执行记录

合法的 `decide_scheme` 只在 `ScopeLocked` 接受。它把取舍结果写入现有父执行 Query `snapshot.scheme`，不另开第二套 Query。记录至少包含：

- `tradeoff`（取舍说明）
- `hypotheses`（假设清单，每项含 `statement` 与分级 `grade`）
- `decided_by`（拍板人）
- `decided_at`（时间，UTC ISO-8601，后缀 `Z`）
- `retrieval`（检索标记：`桩` 或 `真实命中`）

假设分级是封闭集合：`红线级` / `局部` / `候选`。未知分级视为非法 payload。是否存在红线级假设由清单推导，写入 `has_high_risk_assumption`；若客户端同时传入该布尔值且与分级冲突，则拒绝。payload 未提供的技术方案细节保持 `待证`，不臆造。

`decided_at` 由工作流用确定性的 `workflow.now()` 打戳，忽略客户端传入的时间。本票未接真实 RAG，默认路径把 `retrieval` 记为 `桩`，忽略客户端传入的 `真实命中`，避免假装已检索。

缺必填、类型错误、未知分级或未锁范围时拒绝，记入 `last_rejection`，阶段不变，不写入拍板记录。已拍过再次 `decide_scheme` 同样拒绝。

## 分支与停点

- 无红线级假设：`SchemeDecided` 后进入 `TicketsReady`，跳过 Spike。本票停在 `TicketsReady`，不进入 `Implementing`，不派 Coding Child。
- 有红线级假设：`SchemeDecided` 后进入可选 `Spike`，等待 `approve_spike` 或 `abort`。本票不跑 Spike 活动，不写码，不派 Child。`approve_spike` 拒绝则 `Blocked`；接受则进入 `TicketsReady` 后同样停住（与 [DP-18](https://weiperfect007.atlassian.net/browse/DP-18)「过线后只能进 TicketsReady」一致）。
- 未 `decide_scheme`（含仍在 Intake / 仅锁定范围）时，编码路径和 Child 派发不可达。

既有骨架测试若要继续覆盖 Implementing 及之后的路径，可通过 `StoryInput.auto_start_children=True` 暂时进入派 Child；生产与 CLI 默认 `False`，停在 `TicketsReady`。该开关是骨架过渡，[DP-19](https://weiperfect007.atlassian.net/browse/DP-19) 会改为「清单齐才能派 Child」并删除它。

## reopen 不继承方案

`reopen` 只读继承已锁范围的规则保持不变。本票不把方案拍板纳入继承：新执行若已继承完整范围，仍停在 `ScopeLocked` 等待一次新的 `decide_scheme`。是否以及如何只读继承方案记录标 `待证`，等有明确需求再拍，不在本票静默发明。

## 验收与测试

单元与 WorkflowEnvironment 测试证明：未 `decide_scheme`（也仍不可在 `lock_scope` 前）派 Child；合法拍板（无红线级）写入取舍说明 / 分级假设 / 拍板人 / 时间 / 检索标记并进入 `TicketsReady`，不进 Spike、不派 Child；有红线级时写入记录并进入 Spike，不写码、不派 Child；缺必填或非法分级被拒绝且阶段不变、不写记录；Query 可读拍板记录，检索标记为 `桩`。现场 History 打在已运行的官方 Temporal（`TEMPORAL_TARGET`，例如 `host.docker.internal:7233`），覆盖无红线级、红线级进入 Spike、以及缺字段拒绝，不起临时 Temporal 服务。
