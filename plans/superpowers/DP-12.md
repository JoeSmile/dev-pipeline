# DP-12 决策记录

本记录固化 [DP-12](https://weiperfect007.atlassian.net/browse/DP-12) 预算闸门的主流做法。不扩展范围：不实现 RAG 或多模型调度细节（见 [DP-33](https://weiperfect007.atlassian.net/browse/DP-33)），不把写码 / Review 桩改成真实模型调用。

## 计量接口与配置

计量单位为 `tokens`、`calls`、`cost`（整数成本单位，不是已签批币种或单价）。至少启用一个单位。限额来自配置根目录下的 `budget.toml`，由 Activity `load_budget_config` 读取（Workflow 不做文件系统访问）。缺失、无法解析或字段非法时以中文错误可见地失败，不回退到隐藏默认限额，也不继续计费。

样例见 `docs/examples/budget.toml`。文件中的数字一律标为**待证**占位，须经负责人签批后才视为正式限额。代码不得把某一组数字当成已决定的正式配额；测试夹具里的数字同样是待证占位，仅用于可配置性验证。

Worker 启动时也会校验该文件，避免等第一条 Workflow 才失败。

## 闸门挂在父 Workflow

确定性账本在 `dev_pipeline.budget`（无 I/O、无时钟、无随机）。父执行在 bootstrap 之后持有已用 / 限额 / 剩余 / 最后一次超限记录。用量只来自 Activity 返回值（或测试桩），由 Workflow 累加并判线。

互辩、检索、多模型三条耗费用路径的名称是 `debate`、`rag`、`model`，对应桩 Activity `run_debate`、`run_rag`、`run_model_call`。启动入口是父执行上的 Update `start_costly_path`（供测试与后续调度复用）。调用前先检查闸门：任一已启用单位用尽，则不启动 Activity。输入与返回只含路径、用量和是否有新证据，不含密钥、完整提示或思考过程。

## 超限即停（fail-closed）

超限后立刻停止**当前耗费用路径**，并把 `debate` / `rag` / `model` 全部标为不可用，拒绝后续外部模型或检索启动。快照记录 `last_breach`（含字面 `Bad`、路径、超限单位与中文原因，并标明限额待证）。不得静默继续计费。

超限不自动 `abort` 整条 Story，也不取消同 Story 其他未受影响的 Ticket（与 [DP-26](https://weiperfect007.atlassian.net/browse/DP-26) 一致：单张失败不株连同胞）。

同一次父执行内的耗费用启动串行化，避免并发绕过闸门。

## 无新证据即停

桩 Activity 返回 `has_new_evidence=false` 时，只停止**该条**路径并留下可读记录，不再对该路径继续消耗预算。其他仍有预算且未停止的路径可以继续。

## 可查询花费

不另开第二套 Query。已用、限额、剩余、已停止路径和 `last_breach` 挂在现有父执行 `snapshot` 的 `budget` 字段上，与 [DP-27](https://weiperfect007.atlassian.net/browse/DP-27) 对齐。
